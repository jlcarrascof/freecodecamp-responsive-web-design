## Pruebas

- Esperando:1. Debería tener un elemento `h1` para el título principal de la página.
- Esperando:2. Tu `h1` no debe estar vacío.
- Esperando:3. Debes tener sólo un elemento `h1`.
- Esperando:4. Debes tener dos elementos `section`.
- Esperando:5. Dentro del primer elemento `section`, debes tener un elemento `h2` para el título del video que se está reproduciendo.
- Esperando:6. Debajo del elemento `h2`, debes tener un elemento `video`.
- Esperando:7. El elemento `video` debe tener un atributo `controls`.
- Esperando:8. El elemento `video` debe tener un atributo `width` establecido en `640`.
- Esperando:9. Dentro del elemento `video`, debes tener un elemento `source`.
- Esperando:10. El elemento `source` debería tener un atributo `src` que apunte a un archivo de video.
- Esperando:11. El elemento `source` debe tener un atributo `type`.
- Esperando:12. El atributo `type` debe coincidir con el tipo de medio de la extensión de archivo del atributo `src`.
- Esperando:13. Dentro del segundo elemento `section`, debes tener un elemento `h2` para el título de la canción que está sonando.
- Esperando:14. Todos tus elementos `h2` deben contener algún texto.
- Esperando:15. Debajo del elemento `h2`, debes tener un elemento `audio`.
- Esperando:16. El elemento `audio` debe tener un atributo `controls`.
- Esperando:17. El elemento `audio` debe tener un atributo `loop`.
- Esperando:18. El elemento `audio` debe tener un atributo `src` que apunte a un archivo de audio.
